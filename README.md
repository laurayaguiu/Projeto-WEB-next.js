# VELOURS Pâtisserie

Website responsivo desenvolvido para a Velours Pâtisserie com o objetivo de ampliar a presença digital da confeitaria, apresentar seus produtos e facilitar o contato com clientes.

## 🎯 Objetivo

Criar protótipo web moderno e responsivo para divulgação da confeitaria, centralizando informações sobre a marca, cardápio, produtos e canais de contato.

## Prototipação inicial
WireFrame desenvolvido para melhor estruturação das ideias iniciais.

De início, pensamos em um site e-commerce, o qual irá abrangir:
- Uma home page (com seções sobre nós, cardápio, novidades, contatos);
- Um menu de navegação com versão mobile;
- Sobre nós (informações sobre a confeitaria e a confeiteira);
- Menu (com fotos e características dos doces);
- Contatos (tanto página do Instagram como telefone para agendamentos);

## ⚙️ Principais funcionalidades

- Landing page com apresentação da marca
- Navegação entre as principais seções do site
- Catálogo de produtos organizado por categorias
- Páginas dinâmicas para cada categoria do cardápio
- Formulário de contato/cadastro
- Modo claro e escuro com preferência persistente
- Layout responsivo para diferentes tamanhos de tela
- Integração com API externa através de uma API Route do Next.js

## 🛠️ Tecnologias

- Next.js
- React
- JavaScript
- CSS
- HTML
